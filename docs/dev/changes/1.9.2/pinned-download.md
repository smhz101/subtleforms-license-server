type: Fixed
The package address in an update check now names the version it offers, so a site that checked for updates before a new release was published downloads the version it was offered. A version that was yanked, unpublished to a draft, rolled back below with "Make this the latest", or is on another update channel answers "check for updates again" (410) instead of a package that does not match, and a stable site can no longer fetch a beta by editing the version in the address.
