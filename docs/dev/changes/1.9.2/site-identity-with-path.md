A seat is now kept for a site address with its path, so a copy of a site in a subdirectory (example.com/staging) no longer shares the seat of the site at the root, and deactivating one leaves the other. A host-only seat that exists when the server updates is marked as a legacy seat once, by the update itself, and never again from the version a site reports; a stored plugin version never goes down. One host/path site may join a legacy seat and share it, any further path on that host takes a seat of its own, and a legacy seat that has been quiet for 36 hours is handed to the subdirectory site that sends its path (deactivating never does that) or dropped by the daily job once its joined site holds the seat, never when the seat count is read. A site removed in the account or in wp-admin is told so (site_removed) for 30 days, and a connect code for a site with a percent-encoded path now works.
