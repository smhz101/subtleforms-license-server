# Changes in 1.10.1

## Changed

- Failures in payment paths (Paddle lookups, order polling, webhook database writes, account creation) are now written to the WooCommerce log under the source sfls-paddle and, where an order exists, to a private order note.

## Fixed

- A license whose Paddle renewal payment failed now keeps working while Paddle retries it (30 days by default, set under Settings), and My Account tells the customer to update their card.
- A billing or reminder email is marked as sent only after it was sent; a failed billing email is tried again by the daily job, and after three failures the admin sees a notice and the order gets a private note.
