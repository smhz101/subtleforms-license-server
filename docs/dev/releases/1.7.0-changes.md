# License Server 1.7.0: what changed

Every 1.7.0 change since 1.6.0, one commit per item, oldest first. Each LS item has a regression test in tests/integration. Item details and the original bug reports: docs/dev/packages/S170-1.md, docs/dev/packages/S170-2.md and docs/dev/qa/2.3.3/license-server.md.

The branch release/1.7.0 on GitHub held an earlier, untested attempt at the same items (commit ab0b9a7, 15 October). 1.7.0 does not use that code. It is merged into this history with the 1.7.0 code kept, so the two branches no longer conflict, and it stays in history if any of its ideas (audit log, renewal-only coupons, email takeover guard) are picked up later.

Database: the schema version moves to 6, but the tables are the same as 1.6.0. The one-time data changes (license owners from orders, private release file names) run once on init and are tracked by their own options, sfls_owners_migrated and sfls_release_files_private.
