# Changes in 1.10.0

## Removed

- Free trials of paid plans. The free WordPress.org plugin is the trial now. Checkout is always a paid purchase: old links with sfls_trial=1 or 0 still work and add the plan as a normal paid item. The eligibility route (POST /paddle/eligibility), the email code step, the trial reminder and the trial emails are gone, along with the plan trial fields and the trial email settings in Licenses › Settings. A subscription that still arrives from Paddle with the trialing status is handled like an active one. The update drops the wp_sfls_trial_claims and wp_sfls_trial_codes tables, the trial, trial_started_at and trial_ends_at columns of wp_sfls_licenses, and the trial settings (schema 12).

## Fixed

- A fully refunded Paddle renewal order now suspends its license and cancels the Paddle subscription at once, so the subscription stops billing. Partial refunds are unchanged.
