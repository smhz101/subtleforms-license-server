# Changes in 1.9.0

## New

New: The server signs release packages and license answers with an ed25519 key, set up with the sfls signing commands.
New: Replacing a published release zip needs explicit confirmation, and each replacement is logged.

## Changed

Change: New licenses get 25 sites by default, and the license editor needs an explicit site limit.

## Fixed

Fix: Extending a key changes only its expiry, and resume only applies to suspended keys.
Fix: Uninstall, domain and signature column leftovers from the review are fixed.

## Security

Security: Signed packages and answers let SubtleForms Pro refuse a tampered download or a forged license answer.
